Replace or extend this freely -- it is the ground truth this topic's research

## Operator brief (verbatim)

Research how to choose a static site generator for a personal technical blog with fewer than 50 posts.
Cover build speed and developer experience for Hugo, Eleventy (11ty), Astro, and Zola; theming and plugin ecosystem maturity for each; hosting/deployment friction on GitHub Pages, Netlify, and Cloudflare Pages; and migration cost if the author later wants to add a small amount of client-side interactivity.
Exclude full JavaScript framework SPAs (Next.js, Remix) -- this is specifically about static-first generators for content-heavy blogs, not app frameworks.
