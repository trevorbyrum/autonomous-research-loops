# Examples

Fully approved, hash-locked, runnable topics — no brief-writing or review step needed,
just queue and run. Each one exists to prove the engine actually works end to end, not
as content to trust blindly; read a topic's `AUTHORITY.md` before treating its eventual
findings as more than a demo.

| Topic | What it's for |
|---|---|
| [`static-site-generator-choice/`](static-site-generator-choice/) | A small, neutral, finite topic (6 obligations, no external storage) — the fastest way to see one real iteration run. Comparing Hugo/Eleventy/Astro/Zola for a personal blog is deliberately low-stakes; the point is the mechanism, not the answer. |

See the main [README](../README.md#quickstart) for the exact commands to queue and run
one of these.
