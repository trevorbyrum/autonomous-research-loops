# 2d-4b3d: table citations require recorded table availability (V-2)

**Plan.** This is the table half of DOSSIER §2d-4b3b's deferred part: "bind every cited table to recorded availability". Design it in DOSSIER and re-estimate it **before** writing code. Split at about 500 lines.

**Already accepted:**
- SQL 14, admitted acquisitions;
- SQL 15 and SQL 18, all three receipt methods consume a matching admitted acquisition;
- SQL 16 and SQL 19, all three methods are capped at recorded content through the shared view `source_acquisition_content_tiers`, using `recorded-nonblank/1+ucd17.0.0`;
- SQL 17, the non-authority fence on pending extraction.

**The gap.** INVARIANTS V-2 says a claim about a table requires the table to have been accessible. Today a receipt can cite a span with `locator.kind = "table"` while its consumed acquisition records only bibliographic or abstract content, and nothing refuses it.

## Required
1. **The design comes first and is conservative.**
   - Decide from *recorded* evidence only what establishes that a table was available, and write that in DOSSIER.
   - At minimum, a receipt citing a `table` locator requires the consumed acquisition's recorded tier to be at least `full_text`. A table can't be read from a link, a bibliographic record or an abstract.
   - If the recorded response carries structured table data (for example, gateway table identities such as BEA `table:` records), state whether and how it counts. If you can't bind it soundly, refuse rather than infer.
   - Locator labels, route names, record kinds and media types alone never establish table availability.
   - Read the gateway source to see what responses actually record.
2. **Enforcement covers all three receipt methods,** at receipt admission, in ordered additive DDL with a `-- trace:` marker. Reuse the shared content view. Don't fork the content or nonblank rule.
3. **Truthful insufficient access is not a violation.** A `cannot_assess_at_required_tier` receipt that honestly reports a table it couldn't access is admitted, and keeps the existing missing-content hold.
4. **Keep the SQL 17 fence** and every accepted diagnostic.
5. **Tests.**
   - Router and raw-DDL tests for all three methods: a table citation at each insufficient tier, mixed table and non-table spans, a table citation that borrows another acquisition or work's content, the truthful insufficient-access case, and an accepted control.
   - Readback, replay/conflict and rollback.
   - Keep every negative isolated.
   - Add a predicate-level paired mutant for each guard.
