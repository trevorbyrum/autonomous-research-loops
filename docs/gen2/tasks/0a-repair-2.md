## The core pattern behind most of these (read this first)
Every RA finding is the same shape: a schema-valid, individually-plausible record can still disagree with — or be substituted for — the actual authoritative subject it claims to be about. Guards so far check that *a* field is present and well-formed; they don't check that it's *the right one*. Fix at that level, not by patching each symptom separately where you can share a mechanism.

Bound identity/revision/generation fields **by value**, regardless of notation, while preserving legitimate JCS binary64 scientific-number vectors elsewhere. Correct C-13's blanket-refusal wording.
