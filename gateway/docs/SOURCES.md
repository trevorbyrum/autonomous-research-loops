# Sources

Every source the research gateway knows, generated from `research_gateway/registry/seed/sources.toml`. Do not edit this file by hand; edit the seed and run `python -m research_gateway.registry.docs`.

**Personal, non-commercial research use is the baseline for every source listed here** — each was adopted only after its terms were read. The *Commercial* line is the one flag the gateway routes on; a request flagged commercial never touches a source whose verdict is `deny` or `unknown`, and drops individual records without an allow-listed licence from `per-item` sources. Unknowns are stated as unknown rather than guessed.

Rate limits marked *unverified* are conservative defaults; the source stays disabled until the limit is confirmed from documentation or response headers.

Keys are never stored in this repository. Each deployment maps the *secret name* below to an environment variable (`RESEARCH_GATEWAY_SECRET_<NAME>`) or a secrets backend.

## Contents

- Article indexes: Crossref, Directory of Open Access Journals (DOAJ), Europe PMC, OpenAIRE Graph, OpenAlex (local snapshot only), Semantic Scholar
- Dataset and repository indexes: DataCite, GLOBE Project (leadership and culture data), GovInfo (U.S. Government Publishing Office), Harvard Dataverse, Hugging Face Hub, Kaggle datasets, OpenML, Qualitative Data Repository (QDR), Socrata Open Data Network (SODA), World Management Survey (public data)
- Citation graph: OpenCitations
- Resolvers and enrichment: CORE, DOI registration-agency lookup (doi.org), Unpaywall
- Statistical data APIs: BIS Data Portal (SDMX), ECB Data Portal (SDMX), FRED (Federal Reserve Economic Data), U.S. Bureau of Economic Analysis (BEA) Data API, U.S. Bureau of Labor Statistics API, U.S. Census Bureau Data API
- Manual-only sources (documented, never queried by the gateway): Pew Research Center datasets
